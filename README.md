# Book Tracker

A web application to track your reading journey. Keep track of books you've read, are currently reading, and want to read in the future.

## Tech Stack

- Frontend: React (Vite)
- Backend: Express.js
- Database: PostgreSQL
- ORM: Prisma
- Styling: TailwindCSS

## Project Structure

```
book-tracker/
├── client/           # React frontend
├── server/           # Express backend
├── prisma/           # Database schema and migrations
└── README.md
```
